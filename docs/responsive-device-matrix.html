02 · Theme QA

Brand marks and semantic meanings should survive palette changes.

Light

Dark wordmark on light surfaces. Keep borders and secondary copy readable.

Dark

White-wordmark logo variant on dark surfaces. Menus, fields, disabled states and charts remain legible.

Ocean + Forest

Semantic meanings stay consistent as the palette changes.

High Contrast

Focus rings and status text remain clear. Never rely on colour alone.

Responsive branding

Wide shell uses the horizontal lockup. Compact sidebar can use a symbol-only mark.

Persisted preference

Theme may persist; a preview viewport is not real device detection.

03 · Critical application flows

Identity + permissions

Login, expired session, revoked membership, missing permission and no tenant selected.

POS + payment

Empty cart, out of stock, price changes, discount denied, cash, approve, decline, timeout, duplicate click and print failure.

Offline sync

Write offline, kill/restart, duplicate push, rejection, conflict, auth expiry and delta pull during navigation.

Restaurant + delivery

Stale KDS transitions, cancellation policy, driver decline, customer status sync and kitchen/driver race.

Inventory + purchasing

Concurrent terminals, receiving, transfer, count correction, reorder alerts and offline oversell policy.

SaaS admin

Trial expiry, plan downgrade, entitlement removal, tenant suspension and operator audit.

04 · Accessibility acceptance

✓
Keyboard and semantics

Labels for icons/buttons, logical focus order and keyboard navigation for desktop POS/admin.

✓
Touch targets

Generally target at least 44 × 44 CSS px where practical.

✓
Zoom and text scaling

Test 200% browser zoom and OS scaling without clipping or hidden actions.

✓
Status and motion

Do not communicate critical state by colour alone; respect reduced-motion preferences.
