08 · Reliability, privacy & rollout

Start with a narrow vertical slice, not a 137-endpoint implementation dump.

Tenant isolation

Every tenant-owned query is scoped by authenticated membership and resource permission. UUID is not an authorization check.

Idempotency

Same key + same body replays result; same key + different body returns 409.

Offline truth

Persist entity + outbox atomically. First render doesn't wait for sync. ACK/conflict/rejection stay distinct.

Payment safety

Verify provider webhooks and reconcile timeouts. Never infer paid from client callback.

Immutable audit

Append order timeline, payment events, stock movements, invoice issuance and admin changes.

Privacy

No tokens/OTP/card data in localStorage or logs; restrict driver location and media access.

  1. Foundation: auth/session, tenant/RBAC, Flyway, request IDs, idempotency and OpenAPI.
  2. Marketplace slice: catalogue → quote/order → store accept/ready → driver delivery → customer timeline.
  3. Payments/chat: sandbox, webhook/reconciliation, payment tokenization, messages and safety.
  4. Offline POS: Drift migrations, provisional bills, sales, invoices, print jobs and sync conflict UI.
  5. Inventory/admin: receiving, reports, plans/subscriptions, CMS, roles, settings and audit.
  6. Hardening: tenant/concurrency/offline tests, webhook replay, backup/restore and rollback.
