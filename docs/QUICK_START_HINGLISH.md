# Quick Start (Hinglish)

1. Open the repository's **Code** tab and confirm `index.html` and `app.html` are present.
2. Run locally by opening `index.html` in a modern browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.
3. In the top controls, change theme and device width. Inside the app, switch between business modules from the left navigation.
4. To publish, open **Settings → Pages** and check the GitHub Actions deployment. A workflow is included at `.github/workflows/pages.yml`.
5. This is a prototype with sample data, not a production billing or payment system.
