02 · Dummy payment states

Approved · dummy only

Writes a browser-local demo record. No gateway is called and no money moves.

Declined

No order is created; the cart remains available for retry.

Timeout / unknown

Records pending reconciliation, not paid. Real integration must reconcile before retry.

03 · Production checks still required

These cannot be verified by a browser-only static demo.

!
Physical printer output

Test real 58/80 mm thermal and A4 devices, scaling, margins, logo sharpness, cut, reconnect and retry.

!
Real device coverage

Actual Android, iPhone, iPad and desktop tests including keyboard/scanner, accessibility and text scaling.

!
Backend + security

Server auth/RBAC, tenant isolation, transactions, idempotency, durable sync and persistent audit.

!
Legal invoice + payments

Confirm tax jurisdiction, invoice numbering, payment webhooks, unknown-result reconciliation and refunds.

!
Cross-device persistence

The demo uses browser localStorage; separate browsers/devices do not share records.

Do not use for live sales or real customer data. Tax, OTP and subscription values are illustrative; the prototype moves no real money.
